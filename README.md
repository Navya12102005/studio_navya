# Studio Navya — Portfolio & Services Site

Static site (no build step). Open `index.html` or deploy the folder to Vercel / Netlify / GitHub Pages.

- **Add your work:** edit `work.js` — copy a block, change the text. Put images in `assets/work/`.
- **Edit services:** the `SERVICES` list at the top of `main.js`.
- **Your numbers, email & socials:** search `index.html` for `hello@studionavya.com`, `data-count`, and the social links.
